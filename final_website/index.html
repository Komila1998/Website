Project Scope

Domain Overview

Literature Survey

Modern academic project management lacks intelligent automation for team formation, supervisor allocation, and progress monitoring. Existing approaches are mainly manual and static, often leading to poor team balance, mismatched supervision, and delayed project outcomes.

Recent research highlights the use of Machine Learning for clustering students into balanced groups, Natural Language Processing for semantic matching between project topics and supervisor expertise, and LSTM-based models for predicting performance trends.

This project addresses these gaps by implementing a unified AI-driven system using clustering algorithms, NLP-based matching, LSTM-based risk prediction, and a chatbot for real-time academic guidance.

Research Gap

What’s Missing Today

Current academic project systems lack an integrated, intelligent approach to manage team formation, supervisor matching, and progress monitoring. Most solutions operate independently and rely on manual decisions without real-time data analysis.

Research Problem

Core Challenge

How can an AI-driven framework utilize student data, project descriptions, and real-time team activity to automatically form balanced groups, accurately match supervisors, and predict project risks to improve academic project success?

Research Objectives

Four Core Goals

  1. Intelligent group formation using clustering.
  2. Supervisor matching using NLP similarity.
  3. Progress monitoring and risk prediction using LSTM.
  4. Chatbot support for continuous project guidance.
Methodology

Research Approach

This research follows a Design Science approach using a modular AI system. K-Means supports team formation, TF-IDF supports supervisor matching, LSTM predicts team performance, and chatbot APIs provide real-time project guidance.
